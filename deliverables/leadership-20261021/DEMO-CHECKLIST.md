# 领导介绍演示操作清单

材料基线：2026-10-21。建议PPT约10分钟、演示约5分钟。目标是展示“一张图片如何成为可追踪、可下载的OCR任务”，不演示维护或故障注入。

## 一、演示前准备

- [ ] 确认演示时间不与耐久验收冲突。已安排北京时间10月21日19:00至22日约03:00的8小时负载，**该窗口采用报告/已保存结果讲解，不额外提交现场任务**。核对实时状态后再决定后续演示窗口。
- [ ] 从本机打开同目录PPT，检查投影字体和备注。第5页“8小时待最终验收”是本材料时点，如以后验收完成需更新材料，不能口头混淆。
- [ ] 准备一张允许展示的PNG/JPEG。可使用项目 `service-validation/fixtures/upright.png`，它是现有英文文档验收输入；如需中文效果，提前选择经审核的中文测试图片并试跑。
- [ ] 准备受限推理key的私有文件（权限600）、可信公共证书、已批准的私有访问通道。不要展示key、管理员密码、app.env或完整命令环境。
- [ ] 确认原服务未暂停、无UNKNOWN，API/collector正常。由授权运维按 [巡检手册](../../docs/handbooks/OPERATIONS.md)检查；普通讲解者不需要root。
- [ ] 提前用独立工作目录做一次试跑并保存结果。现场与预演用不同新目录；若现场请求响应丢失，重查时必须继续使用现场原目录。
- [ ] 备份方案：提前打开 [P4已保存报告](../../results/maas-p4-release/REPORT.html)，准备原图与已保存result.json。出现连接问题立即切换，明确说明是历史记录，勿冒充实时成功。

## 二、辅助客户端准备

同目录 `demo_ocr.py` 只用Python标准库，默认只验证本地图片，**不发送网络请求**。在仓库根目录执行：

```sh
.venv-maas/bin/python deliverables/leadership-20261021/demo_ocr.py --image service-validation/fixtures/upright.png
```

经批准的演示窗口、确认私有访问已安排后，修改key路径再显式运行。不要把真实key写进命令参数：

```sh
.venv-maas/bin/python deliverables/leadership-20261021/demo_ocr.py \
  --image service-validation/fixtures/upright.png \
  --base-url https://127.0.0.1:18832 \
  --key-file /private/path/inference-key \
  --ca-file .maas/private-tls.crt \
  --output .maas/leadership-demo-live-001 \
  --wait-seconds 40 \
  --run
```

以上不是本次已执行的现场推理。key文件需由管理员安全交付，`.maas/private-tls.crt`为本机已有公开证书。Base URL须指向已建立的实际私有访问通道；脚本不会自行建立SSH或修改服务器。

脚本先保存幂等键和请求体，再提交任务。用**同目录重跑**会复用原键/原请求，不能换新目录来盲目重试同一业务。脚本保存的是当前演示请求，不应多进程同时操作同目录。上传本身无幂等，首次上传后落盘前中断仍可能留下未引用文件；由既有TTL清理。

## 三、5分钟现场步骤与讲解

| 时间 | 操作 | 建议讲解 |
|---|---|---|
| 0:00–0:40 | 展示原图，圈出一段中/英文文字 | “当前先验证普通文字提取，重要结果仍需人工复核。” |
| 0:40–1:30 | 运行已准备的客户端，展示上传文件ID与任务ID | “系统先持久接纳，调用方可以用任务ID追踪。” |
| 1:30–2:30 | 展示QUEUED/RUNNING/SUCCEEDED或最终状态 | “受理不代表立刻执行，系统统一限制并发和队列。”状态可能很快跳过，别为展示排队人为加压 |
| 2:30–3:40 | 打开私有输出目录的result.json，查看outputs.text/lines | “结果包含文字、文本框与置信度，可下载供下游业务使用。” |
| 3:40–4:20 | 用同一工作目录重跑一次或直接查询已知ID（窗口允许时） | “复用的是异步任务幂等记录，不重复创建推理任务。”同目录脚本可能再次下载原结果 |
| 4:20–5:00 | 打开已保存P4报告的监控/恢复证据 | “服务有运行监控和恢复记录，下一步验证真实云网吧动态设备接入。”说明报告是快照 |

可用本机编辑器打开 `.maas/leadership-demo-live-001/result.json`，不投屏私有key目录。现场结果不应把具体样例的行数/耗时讲成通用准确率或SLA。

## 四、异常与停止条件

- 证书/连接错误：不关闭校验、不改网关、不开放公网。切换历史结果并说明原因。
- 超过40秒未完成：脚本结束本地等待，后台任务可能仍在执行。保留request.json和task ID，稍后用同目录查询；不宣称演示超时等于推理取消。
- FAILED/UNKNOWN：记录task ID、时间和错误码，交给运维。不要换幂等键重做、清UNKNOWN或直接重启worker。
- 429/暂停：说明额度或维护保护在工作，停止新增流量，使用历史结果。
- 不执行停节点、容器重启、维护、副本调整、配置变更、清理正式文件或故障注入。

## 五、领导常见问题的回答口径

| 问题 | 回答 |
|---|---|
| 是否已能盈利？ | 已打通试点链路，尚未形成商业收入和完整成本/毛利结论。需用真实可用时长、吞吐、总成本和客户反馈判断 |
| 为什么先OCR？ | 用单张图片业务验证统一服务和运行管理，其他模型后续接入；不引用未经验证的市场份额 |
| 两台GPU是不是可以线性扩展？ | 当前单执行器，未完成多执行器容量对比，不按卡数推算吞吐 |
| 某节点故障其他节点能否一直服务？ | 当前保守全局UNKNOWN隔离与全局维护，逐worker持续服务尚未上线 |
| 云网吧每次IP/主机名变化怎么办？ | E5为P4后的最高优先级，先解决稳定设备身份、可信注册和动态地址，不宣称已适配 |
| 下一阶段需要什么支持？ | 真实云网吧启动/还原信息、环境联系人、少量设备的受控验证窗口和消费者试用反馈 |

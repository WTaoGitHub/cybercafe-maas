E1 本地候选验证报告

2026-10-21。**仅本地模拟通过，E1尚未部署、未接入正式请求链路、未完成GPUStack实机验收。** 本轮没有连接或修改001/002，没有改动今晚19:00的P4测试定时器、镜像、配置或正式数据库。

已实现

- 单worker GPUStack别名契约：独立配置pin、唯一worker selector、单running实例、同revision/镜像、新鲜目标/禁重试证明。

- 按别名验证健康子集，一个模型/worker失败不撤销其他健康模型证明。

- 私有持久落点账本：同步/异步共享容量，单次发送、唯一attempt token、过期/取消/失联UNKNOWN、旧未定位活动保留全局隔离。

- 逐worker排空/故障隔离/停止证据/恢复探针状态机；单模型实例故障独立隔离与恢复；保护001控制端。

- 候选HTTP传输：逻辑模型鉴权后走GPUStack认证别名，无应用重试，按完整响应判断远端是否结束。

验证结果

| 验证 | 结果 |

|---|---|

| E1专项测试 | 48通过，含跨进程容量竞争、持久化失败不发送、UNKNOWN不重放、恢复失败、健康节点在探针期间接单 |

| 全部本地测试 | 135通过、45跳过、1条既有依赖弃用警告 |

| 跳过原因 | 本机未提供独立PostgreSQL测试库；数据库集成测试未在本轮重跑。不是全部生产链路验证通过 |

| 计划维护模拟 | 002撤出后40个同步/异步请求全部经001完成，目标新发送0 |

| 目标停止/恢复模拟 | hook只操作002，001不被停止；真实GPU进程退出尚未验证 |

| 002失联/UNKNOWN模拟 | 未知请求不重放；20个后续健康请求完成；UNKNOWN期间002不判定排空 |

| 模型1无副本模拟 | 模型1明确不可用，模型2继续完成请求 |

HTTP测试替身共收到62次发送（61次成功、1次模拟响应丢失），不是实测吞吐/延迟数据。账本还含1条人为保留的在途intent及2条恢复探针，故完成记录数量与HTTP发送数量不同；无正式计费事件生成。

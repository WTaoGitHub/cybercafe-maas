## 本地核对交付包

先从可信渠道对照压缩包SHA256，解压到空目录（不使用root、不覆盖系统），再执行：

```sh
python3 scripts/maas/verify_worker_bundle.py --root /path/to/extracted-bundle
```

逐文件哈希用于完整性核对，不等于第三方数字签名。公开证书与配置地址仅用于当前测试；正式迁移到稳定局域网控制机时须更新交付材料。

## 角色与入口

- 普通用户使用管理员交付的受限推理API key，通过私有MaaS入口调用服务；没有自助注册、客户管理后台、充值或账单页面。
- 业务/平台管理员在GPUStack中管理模型与推理身份；MaaS的project绑定、目录、配额仍由受信任配置文件和私有CLI管理，没有独立管理员Web后台。
- 运维人员拥有受控SSH/宿主机操作权限，负责维护与恢复。管理员的GPUStack权限不自动等于宿主机root权限；文档中跨角色操作应交给相应人员。
- GPUStack原生Playground属于管理/诊断入口。它与MaaS受控同步/异步入口在模型名、流式能力、配额和计量上不同，不能当作客户任务门户。

## 当前可用范围

001同时承担GPUStack server、worker、MaaS API/单执行器/observer/任务数据库/结果存储；002为worker。GPUStack固定v2.2.3，客户逻辑模型为 `ocr.default`，提供PNG/JPEG中英文普通文字提取。输入与结果持久保存在001的artifact卷，不依赖执行worker在线。

受控入口为私有HTTP 18831与私有TLS 18832，仅回环监听，经管理员授权的SSH转发访问。公网未开放。计划维护为**全局暂停推理、集群模型副本归零后维护002**；UNKNOWN仍全局阻止新的推理。不能承诺其他worker在维护时继续服务。

P4的短项验证已完成，8小时最终验收尚待结果；已保存计划为北京时间2026-10-21 19:00至22日约03:00。此处是文档时点，实时状态以服务器timer/status为准。未实际验证VM断电或Windows/Ubuntu切换；控制端没有HA。

## 文档使用顺序

新开发者先读开发手册；新用户直接读普通用户手册；新管理员先读管理员手册再与运维人员核对权限；所有变更与故障处置以运维手册为入口。旧P1/P2/P3报告保留历史环境描述，不能据其“尚未常驻”等措辞判断当前部署。

# E17 GPU 每日与每月在线时长

## 需求与实施计划

1. 使用 GPUStack v2.2.3 的分页 worker 列表读取状态和 GPU UUID。按 UUID 汇总同一张卡在不同克隆上的记录。worker 名可以携带 UUID 方便核对，统计以控制面上报的 UUID 为准。
2. 运维通过独立定时任务采样，使用独立 SQLite 文件。建议每分钟采样一次，连续有效样本的最大间隔为 120 秒。部署前验证 UUID 跨克隆稳定性及列表权限。
3. 按北京时间自然日查询在线、非 ready 和未知秒数。前一有效样本代表到下一有效样本前的区间；采样失败、过长间隔、卡未上报或 UUID 冲突的区间归为未知。验证旧 worker 记录残留对统计的影响。
4. 增加北京时间自然月查询，将每日时长按 GPU UUID 累加。用固定时间戳验证跨日和月末切分。
5. 在独立状态库完成实机试采，验收后再启用定时采样并开始积累历史。

范围以 GPU 在线时长为限。模型部署时长已移出 E17，下一版采样只读 worker 列表，查询也移除模型时长字段。

## 当前实现与验证状态

首版运维 CLI 已实现日报，当前仍读取模型副本列表并输出模型相关统计。采集与查询的收敛、月报和定时部署待完成。此前使用现有推理凭据试采收到 HTTP 错误，下一次实机验收需验证 worker 列表权限。

```bash
python3 -m maas_platform.gpu_time --db /var/lib/maas-ops/gpu-time.sqlite report 2026-11-04
```

## 1. 优先级与阶段

| 阶段 | 优先级 | 交付物 | 依赖 | 估计有效工程时间 |

| F2 · GPUStack 接入与可靠退出 | P0 | 现有 OCR 适配、租约恢复、节点排空、失败重试 | F1 + F0 探针 | 4–6 人日 |
| F3 · 容量和平台观测 | P1 | 配额、队列上限、指标、计量、压力/恢复报告 | F2 | 3–5 人日 |

## 2. 分类任务与完成标准

### F0 · 协议和边界冻结

- **架构**：确认001常在线；确认控制端权威结果存储和磁盘预算；划分框架与GPUStack职责。
- **接口**：版本化能力描述、模型revision、同步/异步/流式差异、错误码、artifact引用、幂等语义。
- **技术验证**：当前安装版本的实例发现、私有定向推理、SSE、实例重建、健康信息；明确鉴权与地址变化处理。只做最小探针，不重跑模型比较。
- **数据设计**：数据库迁移、租约、尝试token、任务/结果/计量关联与唯一约束。
- **交付**：OpenAPI/schema草案、适配器接口、数据库初稿、connector验证记录。
- **门槛**：确认严格排空可以阻止框架新请求选中目标节点；若探针无法做到，必须调整调用路径，不能把通用网关路由宣称为已支持排空。

### F1 · 单任务持久闭环

- **工程基础**：新增 `platform/`（或不与标准库重名的最终包名）代码区域；配置分离、数据库迁移、Compose开发环境。建议实际Python包名 `maas_platform`，避免遮蔽标准库 `platform`。
- **API/身份**：项目API key摘要、模型目录、输入上传、提交/查询/取消、幂等和错误格式。
- **执行**：PostgreSQL领取租约、心跳、任务截止时间、终态条件提交；单执行器先跑通。
- **存储**：输入/结果权威卷、临时文件原子提交、摘要及到期策略。
- **模拟后端**：延迟、可控失败、进度和取消能力声明；适配器SDK不依赖模型库。
- **门槛**：同幂等键重复提交只产生一个任务；内容不同返回409；提交202后重启API/执行器，任务记录仍在；worker侧无结果时不会伪报成功；跨项目查询被拒。

### F2 · GPUStack 接入与可靠退出

- **后端接入**：把现有OCR接入SDK；私有实例发现、revision绑定、健康状态、并发槽。
- **恢复机制**：租约超时回收、有限重试、旧尝试提交拒绝、OOM隔离、截止时间控制。
- **节点管理**：drain/resume、接单状态与管理员意图分离，统计全部在途占用，旧Playground旁路限制。
- **运行处理**：运行取消与超时后不立即释放未知后端占用；失联重连不自动覆盖drain意图。
- **结果保证**：结果提交控制端后才成功；worker离线后结果仍能查询。
- **门槛**：模拟进程中断、002实例退出/重建、网络短断；任务进入可解释的成功/失败终态，无永久RUNNING；drain生效后不新增目标节点执行租约，强制退出造成的重试可追踪。

### F3 · 容量和平台观测

- **容量**：模型实例资源档案、并发槽、每项目及全局排队上限、排队截止、过载拒绝。
- **公平性**：FIFO+项目并发配额，验证单客户不会占尽全部执行槽；后续再决定加权公平调度。
- **日志/指标**：request/task/attempt关联、队列年龄、延迟、失败、重试、节点和磁盘状态。
- **计量**：唯一成功事件、实际尝试成本、模型真实usage；不产生虚假token。
- **故障观测**：数据库不可达、结果磁盘满、执行器失联及队列积压告警。
- **门槛**：超载不会无限排队；重试不重复记成功用量；能从一个失败任务定位到节点、尝试与错误；性能测试分开报告排队与执行时间。

### F4 · 部署与对外试用

- **交付**：统一镜像仓库、固定digest、配置/secret注入、数据库迁移步骤、升级回退文档。
- **外部入口**：HTTPS、项目鉴权、限流、上传限制；管理服务和GPUStack实例端口仅私网可达。
- **安全验证**：项目隔离、key撤销、artifact授权、路径穿越、任意URL、日志脱敏。
- **运维**：数据库与artifact备份及恢复演练、磁盘预算、过期清理、版本兼容。
- **文档**：SDK/调用示例、状态与错误说明、支持能力及单点边界。
- **门槛**：外部客户独立完成上传→提交→查询→下载；不能访问其他项目、管理API或私有实例；恢复演练能找回已持久化任务及结果，明确备份RPO/RTO测量值。

### F5 · 长时与商业试点

- **稳定性**：至少8小时持续任务，记录失败率、P95、积压、显存及磁盘变化。
- **节点切换**：002主动排空/退出/恢复；有实际条件时执行Windows/Ubuntu切换。普通断连测试不能替代双系统验收。
- **成本**：整机插座功耗、实际可用时长、失败重试、存储及网络成本。
- **客户验收**：真实输入、任务成功/质量验收、延迟目标、保留期和计量核对。
- **门槛**：无无法解释的任务记录丢失/重复成功计量；性能满足事先写定的试点目标；形成可接受边界和继续/暂停扩容决策。8小时单次通过不等于长期SLA。

### F6 · 扩容与更多模型

- **资源池**：新增worker准入、版本一致性、自动分发、退出恢复。
- **后端类别**：接入一种不同输入输出或运行方式的真实模型，验证无核心代码分支。
- **基础设施**：按观测决定对象存储、独立消息队列、独立常在线控制端；控制高可用另行设计。
- **商业能力**：配额产品、账单、成本归集；绘图后再评估视频容量。
- **门槛**：新增后端以适配器和目录配置完成；扩容有量化收益及可控失败边界。

## 3. 跨阶段验证矩阵

| 场景 | 预期行为 | 最晚完成 |
|---|---|---|
| 相同幂等键重复提交 | 同任务ID；不同内容409 | F1 |
| API/执行器在任务期间重启 | 记录保留；租约回收或继续；终态唯一 | F2 |
| 旧尝试延迟提交 | fencing拒绝，不覆盖新终态 | F2 |
| worker中途离线/实例地址变化 | 有限重试或明确失败，目录刷新 | F2 |
| 运行任务取消但模型不支持停止 | 状态语义明确，后端占用未结束不释放槽位 | F2 |
| drain与领取任务竞态 | drain提交后不领取该节点新执行租约 | F2 |
| worker离线后下载已成功结果 | 控制端权威结果可读 | F2 |
| 一个客户大量提交 | 队列/配额有界，其他项目仍可执行 | F3 |
| 数据库或磁盘不可用 | 拒绝新接受；不返回虚假202/成功 | F3 |
| 输入/结果TTL与活动任务重叠 | 活动引用不删；过期结果明确返回410 | F4 |
| 备份恢复 | 可核对记录与artifact，报告实际恢复边界 | F4 |
| Windows/Ubuntu切换 | 排空、离线、上线、缓存/磁盘验证 | F5 |

## 4. 建议代码组织

```text
maas_platform/
  api/                 # 客户API及管理API
  domain/              # 模型、任务、节点状态和策略
  persistence/         # 数据库、迁移、租约、计量
  execution/           # 执行器与协调器
  connectors/gpustack/ # 当前GPUStack版本细节
  artifacts/           # 控制端文件存储及后续对象存储接口
adapter_sdk/           # 轻量能力协议、错误、执行context
adapters/mock/         # 可控故障/延迟后端
adapters/ocr/          # 包装既有OCR，不重复实现算法
deploy/framework/     # Compose、网关、配置示例、备份脚本
tests/framework/      # 协议、恢复、隔离与端到端测试
```

现有 `gpu-ocr/`、实验报告和GPUStack部署脚本先保留；不在设计阶段搬动线上代码。迁移通过明确版本逐步进行，不直接覆盖线上路由。

## 5. 立即执行的第一批任务

1. 将设计中的适配器协议、错误和任务状态落实为schema与接口草案。
2. 用当前部署做connector小探针，验证实例定向调用和排空边界。
3. 建立数据库迁移与任务表，先接模拟后端完成一个持久任务闭环。
4. 用重启、重复提交及过期租约测试证明闭环可靠，再接现有OCR。

本文件为计划，不表示相关组件已经部署；未在本轮修改运行服务或发起长时测试。
